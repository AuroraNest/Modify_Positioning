# Modify Positioning (Android)

无 Root 安卓定位修改 App（V1）。

## 当前能力（V1）

- 固定定位到纽约时代广场：`40.7580, -73.9855`
- 前台服务持续注入模拟定位
- 控制能力：开始 / 暂停 / 停止
- 增强注入模式：周期性微漂移 + 更真实精度/速度字段
- 稳定模式：启动时高频注入 + 服务被回收自动恢复 + WakeLock 保活
- 首次引导：开发者选项、模拟位置信息应用、权限检查
- 诊断页面：展示 mock 授权状态、GPS/Network 最近位置、最近注入记录

## 运行环境

- Android Studio Hedgehog 及以上（建议最新稳定版）
- JDK 17
- Android 10 (API 29) 及以上

## 构建

```bash
./gradlew assembleDebug
```

Debug APK 产物：

`app/build/outputs/apk/debug/app-debug.apk`

## 使用步骤（HyperOS/MIUI 类系统）

1. 安装并打开 App。
2. 在系统“开发者选项”中找到“模拟位置信息应用”，选择本 App。
3. 授予定位权限（必要时授予通知权限）。
4. 回到 App 点击“开始模拟”。
5. 打开地图类 App 验证位置是否显示在时代广场。

## 注意事项

- 无 Root 模式下，模拟定位对系统内读取定位的应用统一生效。
- 部分应用（如高德）存在反模拟检测，可能仍显示真实位置。
- 若系统限制后台，请将本 App 允许后台运行，避免服务被杀。
- 建议在 HyperOS 中把本 App 的电池策略改为“不限制”并锁定后台。
